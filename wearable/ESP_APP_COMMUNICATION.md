# 📡 ESP32 ↔ Android 앱 통신 프로토콜

## 📋 개요

ESP32와 Android 앱 간의 WiFi 통신 프로토콜입니다. GATT 호환 바이너리 프로토콜을 사용하여 BLE 통신으로의 전환이 용이하도록 설계되었습니다.

## 🎯 통신 구조

```
Android 앱 (클라이언트) ←→ ESP32 (서버, 포트 8888)
```

- **ESP32**: 서버 역할 (WiFi TCP 서버, 포트 8888)
- **Android 앱**: 클라이언트 역할 (ESP32에 연결)

## 🎯 통신 방향

### 앱 → ESP32: 점자 시퀀스
- **목적**: 앱에서 생성된 점자 패턴을 ESP32에서 진동으로 출력
- **경로**: Android 앱 → ESP32 (TCP, 포트 8888)
- **용도**: 음성 인식으로 생성된 점자 시퀀스를 ESP32에서 진동 모터로 출력
- **메시지 타입**: `BRAILLE_SEQUENCE` (0x08) - 유일한 점자 전송 방식

### ESP32 → 앱: 입력된 점자 패턴
- **목적**: ESP32에서 입력한 점자 패턴을 앱으로 전송
- **경로**: ESP32 → Android 앱 (TCP, 포트 8888)
- **용도**: ESP32 장갑에서 사용자가 입력한 점자를 앱에서 텍스트로 변환 및 처리
- **메시지 타입**: `PATTERN_COMPLETE` (0x03) - 단일 패턴 완성

## 📦 메시지 프로토콜

### 1. 기본 메시지 구조

모든 메시지는 다음 구조를 따릅니다:

```
[4바이트: 헤더][N바이트: 데이터]
```

#### 헤더 구조 (4바이트)

| 바이트 | 필드 | 설명 | 크기 |
|--------|------|------|------|
| 0 | Message Type | 메시지 타입 | 1바이트 |
| 1-2 | Data Length | 데이터 길이 (Little Endian) | 2바이트 |
| 3 | Checksum | 체크섬 (XOR) | 1바이트 |

#### 데이터 구조

- 데이터 길이는 헤더의 `Data Length` 필드에 명시
- 데이터는 헤더 바로 다음부터 시작
- 최대 데이터 길이: 65535 바이트 (Short 최대값)

### 2. 체크섬 계산

```kotlin
fun calculateChecksum(data: ByteArray): Byte {
    var checksum = 0
    for (byte in data) {
        checksum = checksum xor (byte.toInt() and 0xFF)
    }
    return checksum.toByte()
}
```

체크섬은 데이터 바이트들의 XOR 연산 결과입니다.

## 📨 메시지 타입

### 앱 → ESP32 (점자 시퀀스)

Android 앱에서 ESP32로 점자 패턴을 전송합니다. **앱은 `BRAILLE_SEQUENCE` (0x08)만 사용**하여 점자 패턴을 전송합니다.

| 타입 | 값 | 설명 | 데이터 구조 | 전송 경로 |
|------|-----|------|-------------|-----------|
| `BRAILLE_SEQUENCE` | 0x08 | 점자 패턴 시퀀스 (유일한 점자 전송 방식) | `[패턴 개수(1)][패턴1(1)][패턴2(1)]...` | 앱 → ESP32 |
| `CLEAR` | 0x04 | 점자 초기화 | `[0x00]` (1바이트) | 앱 → ESP32 |
| `WORD_SEPARATOR` | 0x05 | 단어 구분자 (공백) | `[0x00]` (1바이트) | 앱 → ESP32 |
| `SENTENCE_SEPARATOR` | 0x06 | 문장 구분자 | `[0x00]` (1바이트) | 앱 → ESP32 |
| `BRAILLE_SEPARATOR` | 0x07 | 점자 구분자 (개별 점자 모드) | `[0x00]` (1바이트) | 앱 → ESP32 |
| `TEXT_MESSAGE` | 0x10 | 텍스트 메시지 | `[텍스트 길이][텍스트][점자 길이][점자]` | 앱 → ESP32 |
| `SETTINGS` | 0x20 | 설정 | `[속도][모드][플래그]` | 앱 → ESP32 |

#### BRAILLE_SEQUENCE (0x08) - 점자 패턴 시퀀스

**데이터 구조:**
```
[패턴 개수(1바이트)][패턴1(1바이트)][패턴2(1바이트)]...[패턴N(1바이트)]
```

- **첫 바이트**: 패턴 개수 (최대 255개)
- **이후 바이트들**: 각 패턴 (6개 점을 1바이트로 압축)
  - Bit 0: 점 1 (LSB)
  - Bit 1: 점 2
  - Bit 2: 점 3
  - Bit 3: 점 4
  - Bit 4: 점 5
  - Bit 5: 점 6 (MSB)
- **예시**: `0x31` (0b00110001) = 점 1, 4, 5 활성화

**ESP32 처리:**
1. 시퀀스 수신
2. 패턴 개수 확인
3. 각 패턴을 순차적으로 진동 모터에 출력
4. 패턴 간 적절한 지연 시간 적용

#### 구분자 메시지

**CLEAR (0x04)**, **WORD_SEPARATOR (0x05)**, **SENTENCE_SEPARATOR (0x06)**, **BRAILLE_SEPARATOR (0x07)**
- 데이터: `[0x00]` (1바이트)
- 프로토콜 일관성을 위해 1바이트(0x00)를 포함합니다.

#### 점자 시퀀스 전송 예시

**예시 1: "AB" 시퀀스 전송**

```
메시지: "AB" (A=0x01, B=0x03)
헤더: [0x08, 0x03, 0x00, 0x02]  // 타입=0x08, 길이=3, 체크섬=0x02
데이터: [0x02, 0x01, 0x03]      // 개수=2, 패턴1=A(0x01), 패턴2=B(0x03)
전체: [0x08, 0x03, 0x00, 0x02, 0x02, 0x01, 0x03]

ESP32 처리:
1. 시퀀스 수신
2. 패턴 개수 확인 (2개)
3. 첫 번째 패턴 (A, 0x01) → 진동 모터 출력
4. 두 번째 패턴 (B, 0x03) → 진동 모터 출력
```

**예시 2: "hello" 시퀀스 전송**

```
1. CLEAR (0x04) - 점자 초기화
   헤더: [0x04, 0x01, 0x00, 0x00]
   데이터: [0x00]
   전체: [0x04, 0x01, 0x00, 0x00, 0x00]

2. BRAILLE_SEQUENCE (0x08) - "hello" 점자 패턴 시퀀스
   헤더: [0x08, 0x06, 0x00, checksum]  // 길이=6 (개수1 + 패턴5)
   데이터: [0x05, 0x23, 0x19, 0x13, 0x13, 0x1D]  // 개수=5, h,e,l,l,o
   전체: [0x08, 0x06, 0x00, checksum, 0x05, 0x23, 0x19, 0x13, 0x13, 0x1D]

3. SENTENCE_SEPARATOR (0x06) - 문장 구분
   헤더: [0x06, 0x01, 0x00, 0x00]
   데이터: [0x00]
   전체: [0x06, 0x01, 0x00, 0x00, 0x00]
```

**전송 순서:**
1. `CLEAR`로 점자 상태 초기화 (선택사항)
2. `BRAILLE_SEQUENCE`로 여러 점자 패턴을 한 번에 전송
3. 공백이 필요한 경우 `WORD_SEPARATOR` 전송
4. 문장 끝에 `SENTENCE_SEPARATOR` 전송


### ESP32 → 앱 (입력된 점자 패턴)

ESP32에서 Android 앱으로 점자 패턴을 전송합니다. **ESP32는 `PATTERN_COMPLETE` (0x03)를 사용**하여 점자 패턴을 전송합니다.

| 타입 | 값 | 설명 | 데이터 구조 | 전송 경로 |
|------|-----|------|-------------|-----------|
| `PATTERN_COMPLETE` | 0x03 | 단일 패턴 완성 (ESP32에서 입력한 점자 패턴) | `[dotsByte: 1바이트]` | ESP32 → 앱 |
| `DOT_PATTERN` | 0x01 | 개별 점 터치 이벤트 (선택사항) | `[dotIndex: 1바이트]` | ESP32 → 앱 |
| `DOT_RELEASE` | 0x02 | 점 릴리즈 이벤트 (선택사항) | `[dotIndex: 1바이트]` | ESP32 → 앱 |
| `WORD_SEPARATOR` | 0x05 | 단어 구분자 (공백) | `[0x00]` (1바이트) | ESP32 → 앱 |
| `SENTENCE_SEPARATOR` | 0x06 | 문장 구분자 (엔터) | `[0x00]` (1바이트) | ESP32 → 앱 |
| `STATUS_UPDATE` | 0x81 | 상태 업데이트 | `[상태 정보]` | ESP32 → 앱 |
| `MESSAGE_RECEIVED` | 0x82 | 메시지 수신 확인 | `[확인 정보]` | ESP32 → 앱 |
| `SETTINGS_UPDATED` | 0x83 | 설정 업데이트 확인 | `[설정 정보]` | ESP32 → 앱 |
| `IMAGE_DATA` | 0x30 | 이미지 데이터 (필담 OCR용) | `[이미지 크기(4)][이미지 데이터(N)]` | ESP32 → 앱 |

#### PATTERN_COMPLETE (0x03) - 단일 패턴 완성

**데이터 구조:**
```
[dotsByte: 1바이트]
```

- **dotsByte**: 6개 점을 1바이트로 압축
  - Bit 0: 점 1 (LSB)
  - Bit 1: 점 2
  - Bit 2: 점 3
  - Bit 3: 점 4
  - Bit 4: 점 5
  - Bit 5: 점 6 (MSB)
- **예시**: `0x31` (0b00110001) = 점 1, 4, 5 활성화

**ESP32 처리:**
1. 사용자가 점자 패턴 입력 (6개 점)
2. 6개 점을 1바이트로 압축
3. `PATTERN_COMPLETE` 메시지로 Android 앱에 전송
4. 앱에서 점자 패턴을 받아 텍스트로 변환하거나 처리

#### 구분자 메시지

**WORD_SEPARATOR (0x05) - "다음" 버튼**
- 단어 구분자 (공백 의미)
- 앱 → ESP32의 `WORD_SEPARATOR`와 동일한 의미
- 데이터: `[0x00]` (1바이트)

**SENTENCE_SEPARATOR (0x06) - "엔터" 버튼**
- 문장 구분자 (줄바꿈 의미)
- 앱 → ESP32의 `SENTENCE_SEPARATOR`와 동일한 의미
- 데이터: `[0x00]` (1바이트)

#### ESP32 입력 예시

**예시 1: "A" 패턴 전송**

```
ESP32 → Android 앱:
메시지: "A" (점 1 활성 = 0x01)
헤더: [0x03, 0x01, 0x00, 0x01]  // 타입=0x03, 길이=1, 체크섬=0x01
데이터: [0x01]
전체: [0x03, 0x01, 0x00, 0x01, 0x01]

앱 처리:
1. PATTERN_COMPLETE 수신
2. 점자 패턴 (0x01) → 텍스트 "A"로 변환
3. 채팅 메시지로 표시 또는 처리
```

**예시 2: "hello" 입력**

```
1. PATTERN_COMPLETE (0x03) - "h" 점자 패턴
   헤더: [0x03, 0x01, 0x00, checksum]
   데이터: [0x23]  // h 점자 패턴
   전체: [0x03, 0x01, 0x00, checksum, 0x23]

2. PATTERN_COMPLETE (0x03) - "e" 점자 패턴
   헤더: [0x03, 0x01, 0x00, checksum]
   데이터: [0x19]  // e 점자 패턴
   전체: [0x03, 0x01, 0x00, checksum, 0x19]

3. PATTERN_COMPLETE (0x03) - "l" 점자 패턴
   [0x03, 0x01, 0x00, checksum, 0x13]

4. PATTERN_COMPLETE (0x03) - "l" 점자 패턴
   [0x03, 0x01, 0x00, checksum, 0x13]

5. PATTERN_COMPLETE (0x03) - "o" 점자 패턴
   [0x03, 0x01, 0x00, checksum, 0x1D]

6. SENTENCE_SEPARATOR (0x06) - 엔터 버튼
   헤더: [0x06, 0x01, 0x00, 0x00]
   데이터: [0x00]
   전체: [0x06, 0x01, 0x00, 0x00, 0x00]
```

**예시 3: "hello world" 입력 (공백 포함)**

```
1-5. PATTERN_COMPLETE (0x03) - "hello" 각 점자 패턴
   [0x03, 0x01, 0x00, checksum, dotsByte]

6. WORD_SEPARATOR (0x05) - "다음" 버튼 (공백)
   헤더: [0x05, 0x01, 0x00, 0x00]
   데이터: [0x00]
   전체: [0x05, 0x01, 0x00, 0x00, 0x00]

7-11. PATTERN_COMPLETE (0x03) - "world" 각 점자 패턴
   [0x03, 0x01, 0x00, checksum, dotsByte]

12. SENTENCE_SEPARATOR (0x06) - 엔터 버튼
   헤더: [0x06, 0x01, 0x00, 0x00]
   데이터: [0x00]
   전체: [0x06, 0x01, 0x00, 0x00, 0x00]
```
