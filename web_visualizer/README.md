# OFBGlove Web Visualizer

장갑 없이도 시스템을 시연하고 체험할 수 있는 웹 인터페이스입니다. WiFi를 통해 실시간 점자 패턴을 시각화하며, 음성 입력과 웹 점자 입력을 동시에 지원합니다.

## 🚀 빠른 시작

```bash
# 의존성 설치
npm install

# 웹 서버와 TCP/WebSocket 서버 동시 실행
npm run dev
```

서버가 시작되면:
- **웹 인터페이스**: http://localhost:3000
- **TCP 서버**: localhost:8888 (ESP32/Android 앱용)
- **WebSocket 서버**: ws://localhost:8889 (웹 클라이언트용)

## 📱 주요 기능

### 🎯 핵심 기능

#### 실시간 점자 시각화
- **중앙 점자 셀**: 2×3 그리드로 구성된 6개 점 실시간 표시
- **소스별 색상 구분**: 음성 입력(esp32/demo)과 웹 입력(web)을 색상으로 구분
- **표시 모드**: 자동 숨김, 페이드 아웃, 계속 표시 모드 지원
- **장갑 배경**: 점자 입력 영역에 장갑 이미지 배경 표시

#### 문장 시퀀스 관리
- **입력 문장**: 웹에서 직접 입력한 점자 문장 (web 소스)
- **수신 문장**: 음성 입력으로 받은 점자 문장 (esp32/demo 소스)
- **실시간 업데이트**: 입력 즉시 문장에 반영
- **문자/점자 이중 표시**: 각 점자 셀의 문자와 점자 패턴 동시 표시

#### 점자 입력 시스템
- **6점 점자 그리드**: 인터랙티브 점자 입력 인터페이스
- **웹 입력 버퍼**: 전송 전까지 버퍼에 저장
- **공백 처리**: 공백 2회 연속 시 자동 단어 커밋
- **단어 커밋**: 현재 단어를 입력 문장에 추가하고 TTS로 읽기
- **문장 전송**: 버퍼의 모든 패턴을 일괄 전송

#### 재생 제어
- **문장 재생**: 수신 문장을 점자별로 순차 재생
- **다시듣기**: 현재 문장 및 전체 시퀀스 재생
- **재생 모드**:
  - **고정 간격**: 모든 점자를 동일한 간격으로 재생
  - **원본 속도**: 입력 시 측정된 실제 간격 사용
  - **적응형**: 원본 간격을 속도 배율로 조정
- **재생 속도**: 0.1x ~ 5.0x 범위에서 실시간 조절

#### 단어 반복 재생
- **자동 단어 반복**: 문장 완성 시 첫 번째 단어 자동 반복 재생
- **단어 네비게이션**: 이전/다음 단어 탐색
- **단어별 재생**: 각 단어를 점자별로 순차 재생

#### TTS (Text-to-Speech) 통합
- **자동 언어 감지**: 영어 우선, 한글 자동 감지
- **음성 선택**: 최적의 음성 자동 선택 (Google 음성 우선)
- **단어 읽기**: 단어 커밋 시 자동으로 TTS 재생

#### 데이터 수집 및 통계
- **실시간 통계**: 총 패턴 수, 고유 패턴, 분당 평균 등
- **소스별 분류**: esp32, web, demo 소스별 패턴 개수 추적
- **데이터 내보내기**: JSON 형식으로 데이터 내보내기
- **데이터 초기화**: 수집된 데이터 일괄 삭제

#### 연결 모니터링
- **WebSocket 연결 상태**: 실시간 연결 상태 표시
- **연결 정보**: TCP 클라이언트 목록 및 상태 확인
- **서버 로그**: 실시간 서버 로그 확인
- **자동 재연결**: 연결 끊김 시 자동 재연결 시도

### 🔄 고급 기능

#### 구분자 최적화
- **단어 구분자 지연**: 단어 간 구분 시간 설정 (200ms ~ 3000ms)
- **문장 구분자 지연**: 문장 간 구분 시간 설정 (500ms ~ 5000ms)
- **점자 구분자 지연**: 점자 간 구분 시간 설정 (100ms ~ 2000ms)
- **최적화 활성화/비활성화**: 구분자 최적화 기능 토글

#### 표시 시간 설정
- **표시 시간**: 개별 점자 패턴 표시 시간 (0.5초 ~ 10초)
- **점자 간 간격**: 재생 시 점자 간 간격 (0.2초 ~ 5초)
- **프리셋**: 0.5초, 1초, 2초, 3초 빠른 설정

#### 시퀀스 관리
- **전체 시퀀스 보기**: 모든 입력된 점자 시퀀스 확인
- **소스별 필터링**: esp32, web, demo 소스별 필터링
- **상세 정보**: 각 패턴의 바이너리, 문자, 타임스탬프 확인

## 📖 점자 시스템 이해

### 점자 셀 구조
- **점자 셀**: 2×3 그리드로 구성된 6개 점의 조합
- **점 위치**:
  ```
  1 4
  2 5
  3 6
  ```
- **바이너리 표현**: 6비트로 표현 (예: "100110" = 1,4,5점 활성)

### 구분자 시스템
- **점자 구분자**: 개별 점자 셀 간의 구분 (시간 기반)
- **단어 구분자**: 단어 간의 구분 (공백 패턴: 000000)
- **문장 구분자**: 문장 간의 구분 (줄바꿈, 문장 종료)

### 점자 패턴 예시
```
점자 셀 A (100000): ●○○○○○
점자 셀 B (110000): ●●○○○○
점자 셀 C (100100): ●○○●○○
점자 셀 D (100110): ●○○●●○
공백 (000000): ○○○○○○
```

## 🎮 사용법

### 기본 조작

#### 실시간 입력 받기
1. Android 앱에서 WiFi 프로토타입 모드로 서버에 연결
2. 음성 입력 또는 점자 입력 시 실시간으로 화면에 표시
3. 중앙 점자 셀에 현재 패턴 표시
4. 수신 문장 영역에 점자 시퀀스 추가

#### 웹에서 점자 입력하기
1. 하단 점자 입력 영역에서 6개 점 클릭
2. 패턴 완성 후 "다음" 버튼 클릭 (공백 2회 연속 시 자동 커밋)

1. 수신 문장이 있으면 "재생" 버튼 활성화
2. 재생 버튼 클릭 시 점자별로 순차 재생
3. "다시듣기" 버튼으로 현재 문장 재생
4. "초기화" 버튼으로 문장 시퀀스 초기화

## 🔌 통신 프로토콜

### TCP 프로토콜 (ESP32/Android 앱 → 서버)
- **포트**: 8888
- **프로토콜**: 바이너리 프로토콜 (간단한 점자 점 프로토콜)
- **메시지 구조**: 3바이트 (메시지 타입 + 점자 점 + 체크섬)

### WebSocket 프로토콜 (웹 클라이언트 ↔ 서버)
- **포트**: 8889
- **프로토콜**: JSON 메시지
- **메시지 타입**:
  - `braille_pattern`: 점자 패턴 수신
  - `word_separator`: 단어 구분자
  - `sentence_separator`: 문장 구분자
  - `braille_separator`: 점자 구분자
  - `status`: 서버 상태 요청
  - `clients`: 클라이언트 목록 요청

## 🐛 문제 해결

### WebSocket 연결 실패
- 서버가 실행 중인지 확인 (포트 8889)
- 방화벽 설정 확인
- 브라우저 콘솔에서 오류 확인

### TCP 연결 실패
- 서버가 실행 중인지 확인 (포트 8888)
- IP 주소 및 포트 확인
- 네트워크 연결 상태 확인

### 점자 패턴이 표시되지 않음
- WebSocket 연결 상태 확인
- 서버 로그에서 메시지 수신 확인
- 브라우저 콘솔에서 오류 확인
