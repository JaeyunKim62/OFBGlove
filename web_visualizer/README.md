# OFBGlove Web Visualizer

WiFi를 통해 실시간 점자 패턴을 시각화하는 웹 애플리케이션입니다.

## 🚀 빠른 시작

```bash
# 의존성 설치
npm install

# 웹 서버와 TCP/WebSocket 서버 동시 실행
npm run dev
```

## 📱 주요 기능

### 🎯 핵심 기능
- **실시간 점자 시각화**: 2×3 점자 셀 실시간 표시
- **문장 시퀀스**: 실시간 입력을 문장 단위로 그룹화
- **재생 제어**: 다양한 재생 모드와 속도 조절
- **데이터 수집**: 점자 패턴 통계 및 내보내기
- **연결 모니터링**: WebSocket 연결 상태 실시간 확인

### 🔄 사용자 인터랙션 (1단계 구현)
- **다시듣기 기능**: 현재 문장 및 전체 시퀀스 재생
- **네비게이션**: 이전/다음 점자 셀 탐색 (점자셀 하단 배치)
- **구분자 최적화**: 단어/문장/점자 구분자별 시간 텀 설정
- **구분자 마커**: 시각적 구분자 표시 및 토큰 처리 개선

## 📖 점자 시스템 이해

### 점자 셀 구조
- **점자 셀**: 2×3 그리드로 구성된 6개 점의 조합
- **점자간**: 점자 셀 하나 단위 (6개 점의 조합)
- **구분자**: 
  - `점자 구분자`: 개별 점자 셀 간의 구분
  - `단어 구분자`: 단어 간의 구분 (공백)
  - `문장 구분자`: 문장 간의 구분 (줄바꿈)

### 점자 패턴 예시
```
점자 셀 A (100000): ●○○○○○
점자 셀 B (110000): ●●○○○○
점자 셀 C (100100): ●○○●○○
```

## 🔧 포트 설정

- **웹 서버**: 3000번 포트 (React)
- **TCP 서버**: 8888번 포트 (ESP32/Android 앱용)
- **WebSocket 서버**: 8889번 포트 (웹 클라이언트용)

## 🎮 사용법

### 기본 조작
1. **실시간 입력**: ESP32에서 점자 입력 시 실시간으로 화면에 표시
2. **문장 재생**: 문장 구분자 수신 시 자동으로 문장 단위 재생
3. **다시듣기**: 🔄 버튼으로 현재 문장 또는 전체 시퀀스 재생
4. **네비게이션**: 점자셀 하단의 이전/다음 버튼으로 점자 탐색

### 고급 설정
1. **시간 설정**: ⏱️ 버튼으로 표시 시간 및 재생 속도 조절
2. **구분자 최적화**: 단어/문장/점자 구분자별 지연 시간 설정
3. **재생 모드**: 고정 간격, 원본 속도, 적응형 모드 선택

### 시퀀스 관리
- **시퀀스 보기**: 📝 버튼으로 전체 점자 입력 시퀀스 확인
- **데이터 관리**: 데이터 초기화 및 내보내기 기능
- **연결 모니터링**: 📱 연결 정보 및 📋 서버 로그 확인
