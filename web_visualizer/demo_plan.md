목표
- 한 화면에서 핵심 기능만 명확하게 시연한다 (모니터 1대 기준).

데모 핵심 메시지
- 스마트폰에서 음성 인식(스마트폰 측 처리 완료) → WebSocket으로 텍스트 유입(이미 구현 완료)
- 웹에서 6점 점자 입력 → 점자 셀 시각화 + 현재 단어/전체 문장 표시
- 점자 입력 영역 배경에 장갑 이미지 표시

화면 구성(단일 화면)
1) 상단 바: 로고/프로젝트명, 연결 상태(아이콘+텍스트), 연결 토글(Connect/Disconnect) (완료)
2) 중앙 좌측: 점자 셀 시각화(6점) (완료)
3) 중앙 우측: 입력 패널(6점 고정, 컨트롤: 다음, 전송), 하단에 현재 단어 표시
4) 하단: 전체 문장

필수 기능(최소)
- 연결: WebSocket(TCP 브리지), 자동 재시도 포함 (완료)
- 수신: 텍스트/점자 패턴 유입 시 셀 시각화 즉시 갱신, 최근 문자/단어 업데이트
- 송신: 프리셋 제거, 6점 입력 + 다음 + 전송만 제공(무입력 시 공백 처리)
- 점자 점수체계: 6점 고정(8점 옵션 제거)

구현/연동 전제
- 스마트폰 음성 입력 파이프라인은 스마트폰→WebSocket으로 이미 구현됨(추가 개발 불필요)
- 단어 경계 규칙은 기존 구분자 로직을 그대로 사용

입력 동작 규칙
- 다음 버튼: 현재 입력된 점자(아무 점도 선택 안 된 상태 포함=공백)를 셀로 확정하고 커서를 다음 셀로 이동
- 전송 버튼: 지금까지 쌓인 셀들(문장)을 전송
- 공백 처리: 아무 점도 선택하지 않으면 공백으로 확정(현재 UI 표현 유지)

입력 소스 분리
- 스마트폰 입력(음성→텍스트)과 웹 입력(점자)은 구분하여 처리
- 두 소스는 큐를 각각 별도 관리하여 순서/충돌을 방지
- 단어 갱신: 단어 단위로 갱신 (단어 구분자=공백)
- 문장 갱신: 전송 시점에 반영
- 입력이 들어오면 지금까지 있는 것들 초기화
